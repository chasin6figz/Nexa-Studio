# Nexa Studio

A creative resource website for editors and creators.

## Features

- 🎬 Edits
- 📁 Project Files
- 🎨 Presets
- 🎓 Tutorials
- 🎞️ Clips
- 🔐 Admin dashboard
- ☁️ Supabase storage
- 🔎 Resource search and filtering

## Built With

- HTML
- CSS
- JavaScript
- Supabase

## Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/nexa-studio.git
cd nexa-studio
```

Install dependencies:

```bash
npm install
```

Create a `.env` file and add your Supabase details:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_PUBLISHABLE_KEY=your_supabase_key
```

Run the project:

```bash
npm run dev
```

## Supabase

Supabase is used for:

- Authentication
- Database
- File storage
- Resource management
